Aplicación sencilla desarrollada con **Java y Spring Boot** para practicar la creación y prueba de endpoints HTTP relacionados con la gestión de alumnos.

## Objetivo

Familiarizarse con el desarrollo backend en Spring Boot, el manejo de rutas y controladores y las peticiones HTTP mediante **Postman**.

## Tecnologías

- **Java 21** — Lenguaje de programación.
- **Spring Boot 3.4.3 / Spring Web** — Desarrollo de la aplicación y sus endpoints.
- **Maven** — Gestión de dependencias y ejecución.
- **Postman** — Prueba de endpoints.

## Ejecución

Clona el repositorio:

```bash
git clone https://github.com/Sam-ai06/gestion-alumnos-SpringBoot.git
cd gestion-alumnos-SpringBoot
```

Ejecuta la aplicación con Maven Wrapper:

```bash
./mvnw spring-boot:run
```

En Windows, utiliza `mvnw.cmd spring-boot:run`.

Una vez iniciada la aplicación, puedes probar los endpoints implementados con **Postman**.
